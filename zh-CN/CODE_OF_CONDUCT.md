# Contributor Covenant 行为准则

## 我们的承诺

作为成员、贡献者与领导者，我们承诺让社区参与成为人人免受骚扰的体验，不论年龄、体型、可见或不可见的残疾、族裔、性征、性别认同与表达、经验水平、教育、社会经济地位、国籍、外貌、种族、种姓、肤色、宗教，或性认同与性取向。

我们承诺以有助于开放、友好、多元、包容与健康社区的方式行动与互动。

## 我们的标准

有助于积极环境的行为示例包括：

- 对他人表现出同理心与善意
- 尊重不同意见、观点与经历
- 给予并优雅地接受建设性反馈
- 承担责任，向受我们错误影响的人道歉，并从经验中学习
- 关注的不只是个人利益，而是整体社区的最佳利益

不可接受的行为示例包括：

- 使用性化语言或意象，以及任何形式的性关注或挑逗
- 引战、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可发布他人隐私信息，例如实体或电子邮箱地址
- 在专业场合可被合理视为不当的其他行为

## 执行责任

项目维护者负责澄清并执行可接受行为标准，并对他们认为不当、威胁、冒犯或有害的行为采取适当且公平的纠正措施。

维护者有权且有责任移除、编辑或拒绝与本行为准则不符的评论、提交、代码、wiki 编辑、issue 及其他贡献，并在适当时说明管理决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共空间正式代表社区时。

## 执行

辱骂、骚扰或其他不可接受行为的实例，可向负责执行的项目维护者报告：

- **发布后：** 使用托管本项目的仓库或组织在 GitHub（或对应 forge）上的私有维护者联系 / 管理工具。
- **在此之前 / 镜像：** 使用已由分发本树的人分享的私有渠道 —— 本仓库不捏造邮箱地址。

与安全相关的报告遵循 [`SECURITY.md`](SECURITY.md)（启用后优先使用私有漏洞通告）。所有投诉将得到及时、公平的审查与调查。

所有项目维护者都有义务尊重任何事件报告者的隐私与安全。

## 执行指南

项目维护者在判定违反本行为准则的行为后果时，将遵循以下社区影响指南：

### 1. 纠正

**社区影响**：使用不当语言，或其他被认为不专业或不受欢迎的行为。

**后果**：来自维护者的私下书面警告，澄清违规性质，并说明为何行为不当。可能要求公开道歉。

### 2. 警告

**社区影响**：单次违规或一系列行为。

**后果**：警告并说明持续行为的后果。在指定时间内，不得与相关人员互动，包括主动与执行行为准则的人互动。这包括避免在社区空间以及外部渠道（如社交媒体）进行互动。违反这些条款可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在指定时间内暂时禁止与社区进行任何形式的互动或公开交流。在此期间不得与相关人员进行公开或私下互动，包括主动与执行行为准则的人互动。违反这些条款可能导致永久封禁。

### 4. 永久封禁

**社区影响**：表现出违反社区标准的模式，包括持续的不当行为、骚扰个人，或对某类个体的攻击性或贬损行为。

**后果**：永久禁止在社区内进行任何形式的公开互动。
