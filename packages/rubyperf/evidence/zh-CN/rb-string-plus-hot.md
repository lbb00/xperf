# rb-string-plus-hot — string += 与 <<

## 主张

在这台机器上测量：主热案例 **`str_plus`** 比例前/后约 **~53.79×**（之后更快）。默认严重性保持 **`off`**。单凭此填充不要升级为 `error`——比例很高，但策略/默认设置和 G3 OK-惯用历史保持严重性不变。

## 如何测量

- 测试工具：`packages/rubyperf/examples/bench/evidence_rb.rb`
- 协议：预热=3；9轮的中位数；在适用的地方进行垃圾收集/收集
- 原始数据行：[`rb-string-plus-hot.jsonl`](../rb-string-plus-hot.jsonl)

## 与 lint 的对应

`rubyperf-lint` **rb-string-plus-hot** 默认保持 **`关闭`**。推荐升级：**否**。

## 限制

- 微基准；不是应用程序性能概况。
- 小行数可能接近计时器噪声；对于比例声明，建议使用热（非小）案例。
- I/O 规则（print/echo/puts/writeln）丢弃到 `/dev/null` — 取决于环境。
