# rb-puts-hot — 每次用 puts 与 用 join 一次

## 主张

在这台机器上测量：主要热案例 **`puts_each`** 比率前/后约 **3.58×**（之后更快）。默认严重性保持 **`off`**。仅凭此填充不要升级到 `error`。

## 如何测量

- 测试工具：`packages/rubyperf/examples/bench/evidence_rb.rb`
- 协议：预热=3；9轮的中位数；在适用的地方进行垃圾收集/收集
- 原始数据行：[`rb-puts-hot.jsonl`](../rb-puts-hot.jsonl)

## 运行时（本证据文件）

| Field | Value |
|-------|--------|
| 时间 | 2026-10-22 亚洲/上海（机器时钟；JSONL 时间戳是 UTC） |
| Toolchain | **Ruby 4.0.8** |
| 中位数（`join_once` 之后） | 1.149000 毫秒（操作=20000，比率=1.000000） |
| 中位数之前 (`puts_each`) | 4.110000 毫秒 (操作=20000, 比率=3.577023) |
| **前/后主要比率** | **~3.58×** (`puts_each`) |

方向和绝对毫秒数对机器/工具链/选项敏感。在工具链或机器更改后，请重新运行测试环境。

## 与 lint 的对应

`rubyperf-lint` **rb-puts-hot** 默认保持 **`关闭`**。推荐升级：**否**。

## 限制

- 微基准；不是应用程序配置文件。
- 小 N 行可能接近计时器噪声；对于比例声明，更喜欢热（非小）情况。
- I/O 规则（print/echo/puts/writeln）丢弃到 `/dev/null` — 依赖环境。
