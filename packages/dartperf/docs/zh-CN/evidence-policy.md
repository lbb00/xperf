# dartperf 证据政策

## 门槛

一条规则只有在有 `evidence/<RULE>.md` + `.jsonl` **以及**明确的政策决定的情况下才可以被视为 **`error`**。仅测量的 JSONL 并不会自动升级。批次 B（2026-10-22）保持了软件包默认设置。
