# C# 性能指南（v0）

少做会重新分配的 list，让热路径更安静。

> **范围：现代 C#（.NET）。** 声称加速的断言会点名本地示例，或标明暂定。**Corpus lint 计数是启发式 dogfood**，不是基准。

## 如何阅读

1. 先**测量**（BenchmarkDotNet、`dotnet-trace`）。
2. 把每一章当核对清单。
3. 运行时 / GC 设置不同——请重测。
