# ph-string-dot-hot — 字符串 .= 与 implode

## 主张

在这台机器上测量：主要热情况 **`str_dot`** 比率前/后约 **~2.54×**（之后更快）。默认严重性保持 **`off`**。仅凭此填充 **不要** 升级到 `error`。

## 如何测量

- 测试套件：`packages/phpperf/examples/bench/evidence_ph001_ph003.php`
- 协议：预热=3；9轮的中位数；在适用时进行垃圾回收/收集
- 原始数据行：[`ph-string-dot-hot.jsonl`](../ph-string-dot-hot.jsonl)

## 与 lint 的对应

`phpperf-lint` **ph-string-dot-hot** 默认保持 **`关闭`**。推荐升级：**否**。

## 限制

- 微基准；不是应用程序性能分析。
- 小样本行数可能接近计时器噪声；对于比例声明，建议使用热（非小）案例。
- I/O 规则（print/echo/puts/writeln）会丢弃到 `/dev/null` — 取决于环境。
