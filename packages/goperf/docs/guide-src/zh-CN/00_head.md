# Go 性能指南（v0）

少一点分配噪声，少一点意外的 `fmt` / 字符串增长停顿。

> **范围：Go 1.21+。** 声称加速的断言会点名本地示例、上游来源，或标明暂定。**Corpus lint 计数是启发式 dogfood**，不是基准。

## 如何阅读

1. 先**测量**（`go test -bench`、`pprof`、`benchstat`）。
2. 把每一章当核对清单，不是强制重写令。
3. 逃逸分析与内联会改变成本——工具链升级后请重测。
