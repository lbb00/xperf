# Python 性能指南（v0）

少做平方级 builder，让热路径更安静。

> **范围：CPython 3.10+。** 声称加速的断言会点名本地示例，或标明暂定。**Corpus lint 计数是启发式 dogfood**，不是基准。

## 如何阅读

1. 先**测量**（`timeit`、`py-spy`、`cProfile`）。
2. 把每一章当核对清单。
3. PyPy / 其他 VM 不同——请重测。
