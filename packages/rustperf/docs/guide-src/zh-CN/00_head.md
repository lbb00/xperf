# Rust 性能指南（v0）

少一点分配器噪声，少一点意外的字符串 / 打印停顿。

> **范围：Rust edition 2021+。** 声称加速的断言会点名本地示例、上游来源，或标明暂定。**Corpus lint 计数是启发式 dogfood**，不是基准。

## 0. 范围与方法

1. 先**测量**（`cargo bench`、`criterion`、`perf`）。
2. 把每一章当核对清单，不是强制重写令。
3. LLVM 优化会改变成本——工具链升级后请重测。
